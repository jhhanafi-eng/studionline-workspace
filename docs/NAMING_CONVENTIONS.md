# Naming Conventions

## Folders
Use lowercase kebab-case: `framework-modules`, `client-projects`, `starter-templates`.

## Files
Use lowercase kebab-case and include the responsibility: `auth-service.md`, `routing-guide.md`, `invoice-engine.md`.

## Code Symbols
- Functions: `createSession`, `validatePermission`, `renderDashboard`.
- Variables: `currentUser`, `invoiceTotal`, `routeConfig`.
- Constants: `DEFAULT_TIMEZONE`, `SESSION_TTL_SECONDS`.
- Error codes: `AUTH_UNAUTHORIZED`, `DB_RECORD_NOT_FOUND`.

## Version Names
Framework, template, and application releases use Semantic Versioning in the form `MAJOR.MINOR.PATCH`.
