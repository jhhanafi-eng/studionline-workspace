# Contributing

Every human contributor and AI assistant must read the following before making changes:
- `AI_CONTEXT.md`
- `ENGINEERING_ARCHITECTURE.md`
- `FRAMEWORK_SPECIFICATION.md`
- `CODING_STANDARDS.md`
- `PROJECT_CREATION_GUIDE.md`

## Contribution Rules
- Preserve the approved architecture.
- Avoid duplicated logic.
- Never rewrite unrelated modules.
- Always update documentation when behavior, contracts, structure, or decisions change.
- Always explain architectural decisions in commits, pull requests, or design notes.
- Keep reusable assets in the framework workspace.
- Keep client-specific logic isolated.
- Ensure products remain independent.
- Never introduce framework dependencies on client projects.
