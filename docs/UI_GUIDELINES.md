# UI Guidelines

## Application Model
STUDIONLINE web apps should use a Single Page Application experience where practical, with clear route state, responsive layout, and reusable component contracts.

## Layout
Dashboards use a header, sidebar, content region, optional secondary panel, and footer. Layouts must adapt to desktop, tablet, and mobile widths.

## Patterns
- Sidebar: persistent on desktop, collapsible on smaller screens.
- Cards: concise summaries with clear labels and actions.
- Forms: grouped fields, inline validation, explicit save and cancel actions.
- Tables: readable density, search, filters, pagination, and empty states.
- Charts: support accessible summaries and avoid color-only meaning.
- Navigation: consistent hierarchy, active state, and permission-aware visibility.

## Readiness
Design must be dark-mode ready, accessible, keyboard navigable, and visually consistent across products.
