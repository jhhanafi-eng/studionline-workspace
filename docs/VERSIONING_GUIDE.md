# Versioning Guide

STUDIONLINE uses Semantic Versioning: `MAJOR.MINOR.PATCH`.

## Major
Increment for breaking public interface changes, structural migrations, or incompatible data contract changes.

## Minor
Increment for backward-compatible features, new modules, new extension points, or additive template capabilities.

## Patch
Increment for backward-compatible fixes, documentation corrections, and non-breaking refinements.

## Version Domains
Framework versions describe reusable platform contracts. Template versions describe starter project baselines. Application versions describe deployable products and client applications.
